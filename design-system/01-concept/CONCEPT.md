## 디자인 원칙

### 1. 단순함 (Simplicity)
- 불필요한 요소 제거
- 핵심 기능에 집중
- 텍스트 최소화, 시각적 표현 우선

### 2. 직관성 (Intuitive)
- 설명 없이도 이해되는 UI
- 익숙한 패턴 활용
- 명확한 시각적 위계

### 3. 부드러움 (Soft)
- 둥근 모서리
- 부드러운 그림자
- 여유로운 여백

### 4. 세련됨 (Refined)
- 절제된 색상 사용
- 정교한 타이포그래피
- 디테일에 신경

### 5. 유연함 (Flexible)
- 반응형 레이아웃
- 다양한 콘텐츠 대응
- 확장 가능한 구조

## 모션 원칙

부드럽고 세련된 느낌을 위한 애니메이션 적용:

| 요소 | 애니메이션 | 예시 |
|------|-----------|------|
| 버튼/링크 | 부드러운 호버 전환 | 색상, 그림자 변화 |
| 카드 | 미세한 lift 효과 | hover 시 살짝 떠오름 |
| 모달/드롭다운 | fade + scale | 자연스러운 등장/퇴장 |
| 펼침/접힘 | ease-out 슬라이드 | 아코디언, 필터 영역 |
| 페이지 전환 | fade 또는 slide | 부드러운 화면 전환 |

### 모션 특성
- **속도**: 200-400ms (너무 빠르지도 느리지도 않게)
- **이징**: ease-out, ease-in-out (자연스러운 감속)
- **강도**: 미세하게 (과하지 않게)

---

## 하지 않을 것 (Don'ts)

- ❌ 화려한 그라디언트
- ❌ **과도한/현란한** 애니메이션 (부드러운 전환은 OK)
- ❌ 복잡한 장식 요소
- ❌ 빽빽한 텍스트
- ❌ 강렬한 색상 남발
- ❌ 각진 모서리
- ❌ 날카로운 그림자
- ❌ 뚝뚝 끊기는 전환 (애니메이션 없는 상태 변화)

---

## 시각적 방향 요약

| 요소 | 방향 |
|------|------|
| **색상** | 차분한 블루 계열, 높은 명도, 낮은 채도 |
| **모서리** | 큰 래디어스 (8-16px) |
| **여백** | 넉넉하게, 콘텐츠 사이 충분한 공간 |
| **그림자** | 미세하고 부드럽게, blur 큰 값 |
| **타이포** | 크기 차이 명확, 두께는 400/600 위주 |
| **밀도** | 낮음, 한 눈에 파악 가능 |
