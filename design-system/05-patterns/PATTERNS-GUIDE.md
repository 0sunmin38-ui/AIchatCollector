# 패턴 가이드

> 컴포넌트를 조합한 더 큰 UI 단위를 정의합니다.
> KRDS의 "기본 패턴"과 "서비스 패턴" 개념을 참고합니다.

---

## 패턴이란?

```
토큰 → 컴포넌트 → 패턴 → 페이지
                    ↑
              지금 이 단계
```

패턴 = **반복되는 UI 조합** = **사용자 과업 단위**

---

## 패턴의 종류

### 기본 패턴 (Foundation)

핵심 과업 수행 시 반복되는 UI 집합

| 패턴 | 설명 | 구성 컴포넌트 |
|------|------|---------------|
| 입력 폼 | 데이터 입력 | Input + Label + Button |
| 오류 처리 | 에러 표시 | Alert + Message + Action |
| 로딩 상태 | 대기 표시 | Skeleton / Spinner |
| 빈 상태 | 데이터 없음 | Illustration + Message + CTA |
| 확인 대화 | 위험 액션 전 | Modal + Text + Buttons |

### 서비스 패턴 (Service)

사용자 여정의 반복 단위

| 패턴 | 설명 | 구성 |
|------|------|------|
| 검색 | 데이터 찾기 | SearchInput + Filters + Results |
| 목록 | 데이터 나열 | List/Grid + Pagination + Sort |
| 상세 보기 | 단일 항목 | Header + Content + Actions |
| 선택 + 액션 | 일괄 처리 | Checkbox + SelectionBar + Actions |
| 네비게이션 | 페이지 이동 | Header + Sidebar + Breadcrumb |

## 이 프로젝트의 주요 패턴

현재 프로젝트(AIchatCollector)에서 사용되는 패턴:

### 1. 검색 + 필터 패턴

```
┌─────────────────────────────────────────┐
│  [🔍 검색...]  [정렬 ▼]                 │
├─────────────────────────────────────────┤
│  [분류1] [분류2] [분류3] ...  ← 스크롤  │
├─────────────────────────────────────────┤
│  [태그1] [태그2] [태그3] ...  ← 스크롤  │
└─────────────────────────────────────────┘
```

**구성:**
- SearchInput (검색창)
- Select (정렬 드롭다운)
- ChipGroup (분류 필터)
- ChipGroup (태그 필터)

**상태:**
- 기본: 모든 필터 해제
- 필터 적용: 활성 필터 하이라이트
- 검색 중: 로딩 표시
- 결과 없음: 빈 상태 패턴

### 2. 카드 목록 패턴

```
┌─────────────────────────────────────────┐
│ ☐ 제목                        [분류]   │
│   메타정보 | 통계                       │
│   ─────────────────────────────────     │
│   본문 내용 (펼침 가능)                 │
└─────────────────────────────────────────┘
```

**구성:**
- Checkbox (선택)
- Card (컨테이너)
- Badge (분류)
- Text (제목, 메타, 본문)
- Expandable (펼침/접기)

### 3. 선택 + 액션 패턴

```
┌─────────────────────────────────────────┐
│ 3개 선택됨  [전체선택]  [태그입력]      │
│             [분류 ▼]   [삭제]           │
└─────────────────────────────────────────┘
```

**구성:**
- Counter (선택 개수)
- Button (전체 선택/해제)
- Input (태그 입력)
- Select (분류 변경)
- Button (삭제)

**상태:**
- 숨김: 선택 없음
- 표시: 1개 이상 선택
- 처리 중: 액션 진행 중

### 4. 반응형 헤더 패턴

```
Desktop:
┌─────────────────────────────────────────┐
│ 브랜드  [Nav1] [Nav2] [Nav3]  [Actions] │
└─────────────────────────────────────────┘

Mobile:
┌─────────────────────────────────────────┐
│ 브랜드              [≡]                 │
└─────────────────────────────────────────┘
│ [Nav1] [Nav2] [Nav3]        (접힘 가능) │
```

## 패턴 정의 형식

```markdown
## 검색 + 필터 패턴

### 구조
- SearchInput: 좌측, flex-grow
- SortSelect: 우측, 고정 너비
- FilterChips: 전체 너비, 가로 스크롤

### 레이아웃
| 요소 | 모바일 | 데스크톱 |
|------|--------|----------|
| 검색창 | 100% | flex-grow |
| 정렬 | 100% (2행) | 120px |
| 필터 | 스크롤 | 스크롤 |

### 상호작용
1. 검색어 입력 → 실시간 필터링 or Enter 시 검색
2. 정렬 변경 → 즉시 재정렬
3. 필터 클릭 → 토글 (다중 선택)
4. 필터 해제 → 전체 보기

### 반응형
- 900px 이하: 도구 영역 접기 가능
- 600px 이하: 정렬이 검색 아래로

### 접근성
- 검색창: / 키로 포커스
- 필터: 키보드 탐색 가능
- 활성 필터: aria-pressed="true"
```

## 패턴과 컴포넌트의 차이

| 구분 | 컴포넌트 | 패턴 |
|------|----------|------|
| 단위 | UI 요소 | 사용자 과업 |
| 예시 | Button | 검색 폼 |
| 재사용 | 어디서나 | 특정 맥락 |
| 정의 | 스타일 + 상태 | 구조 + 상호작용 + 레이아웃 |

## KRDS 패턴 참고

KRDS는 패턴을 두 단계로 구분:

### 기본 패턴
- 개인정보 입력
- 오류 처리
- 입력 폼
- 확인/알림

### 서비스 패턴
- 검색
- 로그인/인증
- 신청/제출
- 결과 조회

→ 자세한 내용: `references/KRDS-GUIDE.md`
