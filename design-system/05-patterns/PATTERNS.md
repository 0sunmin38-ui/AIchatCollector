# UI 패턴

> 컴포넌트를 조합한 사용자 과업 단위

---

## 1. 검색 + 필터 패턴

데이터를 찾고 좁히는 패턴.

### 구조

```
┌─────────────────────────────────────────────────────┐
│  [🔍 검색...]                        [정렬 ▼]      │
├─────────────────────────────────────────────────────┤
│  [전체] [분류1] [분류2] [분류3] ...    ← 가로 스크롤│
├─────────────────────────────────────────────────────┤
│  [태그1] [태그2] [태그3] ...           ← 가로 스크롤│
└─────────────────────────────────────────────────────┘
```

### 구성 컴포넌트

| 컴포넌트 | 역할 |
|----------|------|
| Input (search) | 텍스트 검색 |
| Select | 정렬 옵션 |
| Chip Group | 분류 필터 (단일 선택) |
| Chip Group | 태그 필터 (다중 선택) |

### 레이아웃

| 요소 | Desktop | Mobile |
|------|---------|--------|
| 검색창 | flex-grow | 100% |
| 정렬 | 120px 고정 | 100% (2행) |
| 필터 | 가로 스크롤 | 가로 스크롤 |
| 도구 영역 | 항상 표시 | 접기 가능 |

### 상호작용

1. 검색어 입력 → 실시간 필터링 또는 Enter
2. 정렬 변경 → 즉시 재정렬
3. 분류 클릭 → 단일 선택 (라디오)
4. 태그 클릭 → 토글 (다중 선택)
5. 필터 해제 → "전체" 클릭

### 반응형

| 브레이크포인트 | 변화 |
|----------------|------|
| 1024px+ | 모든 요소 한 줄 |
| 768px- | 정렬이 검색 아래로 |
| 600px- | 도구 영역 접기 토글 표시 |

## 2. 카드 리스트 패턴

항목을 나열하고 탐색하는 패턴.

### 구조

```
┌─────────────────────────────────────────────────────┐
│ ☐ 제목                                    [분류]   │
│   부가정보 · 메타데이터                             │
├─────────────────────────────────────────────────────┤
│   본문 내용 (펼침 가능)                             │
│   [이미지] [댓글]                                   │
└─────────────────────────────────────────────────────┘
```

### 구성 컴포넌트

| 컴포넌트 | 역할 |
|----------|------|
| Checkbox | 항목 선택 |
| Card | 컨테이너 |
| Badge | 분류 표시 |
| Text | 제목, 메타, 본문 |
| Expandable | 펼침/접힘 영역 |

### 레이아웃

| 요소 | 설명 |
|------|------|
| 카드 간격 | 12px |
| 카드 패딩 | 20px (desktop), 16px (mobile) |
| 체크박스 | 좌측 고정 |
| 분류 배지 | 우측 상단 |

### 상태

| 상태 | 표현 |
|------|------|
| 기본 | 테두리만 |
| 호버 | lift + shadow |
| 선택됨 | primary-light 배경 |
| 펼침 | 본문 영역 표시 |

### 빈 상태

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│              [일러스트레이션]                       │
│                                                     │
│            검색 결과가 없습니다                     │
│         다른 키워드로 검색해보세요                  │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 3. 선택 + 액션 패턴

여러 항목을 선택하고 일괄 처리하는 패턴.

### 구조

```
┌─────────────────────────────────────────────────────┐
│  3개 선택됨   [전체선택]  [태그 입력...]            │
│               [전체해제]  [분류 ▼] [삭제]           │
└─────────────────────────────────────────────────────┘
```

### 구성 컴포넌트

| 컴포넌트 | 역할 |
|----------|------|
| Counter | 선택 개수 표시 |
| Button | 전체 선택/해제 |
| Input | 태그 입력 |
| Select | 분류 변경 |
| Button (danger) | 삭제 |

### 상태

| 상태 | 표현 |
|------|------|
| 숨김 | 선택 없음 (0개) |
| 표시 | 1개 이상 선택 |
| 처리 중 | 버튼 로딩 상태 |

### 위치

| 환경 | 위치 |
|------|------|
| Desktop | 상단 고정 (sticky) |
| Mobile | 하단 고정 (fixed bottom) |

### 반응형

| 브레이크포인트 | 변화 |
|----------------|------|
| 768px+ | 가로 배치 |
| 768px- | 2줄 또는 하단 시트 |

## 4. 헤더 + 네비게이션 패턴

페이지 이동과 전역 액션.

### Desktop 구조

```
┌─────────────────────────────────────────────────────┐
│  Logo  부가설명    [Nav1] [Nav2] [Nav3]   [Actions] │
└─────────────────────────────────────────────────────┘
```

### Mobile 구조

```
┌─────────────────────────────────────────────────────┐
│  Logo                                    [≡ 메뉴]   │
├─────────────────────────────────────────────────────┤
│  [Nav1] [Nav2] [Nav3]              (접힘 가능)      │
└─────────────────────────────────────────────────────┘
```

### 구성 컴포넌트

| 컴포넌트 | 역할 |
|----------|------|
| Logo | 브랜드 |
| Nav Links | 페이지 이동 |
| Button | 주요 액션 |
| Menu Toggle | 모바일 메뉴 |

### 레이아웃

| 속성 | 값 |
|------|-----|
| Height | 64px |
| Padding | 0 24px |
| Position | sticky, top: 0 |
| Background | white + blur (옵션) |
| Border | bottom 1px |
| Z-index | 100 |

### 반응형

| 브레이크포인트 | 변화 |
|----------------|------|
| 900px+ | 로고 + 네비 + 액션 한 줄 |
| 900px- | 네비 접기 토글 표시 |
| 480px- | 로고 심볼만, 간소화 |

## 5. 모달 확인 패턴

위험하거나 중요한 액션 전 확인.

### 5-1. Alert Dialog (2버튼)

간단한 확인/취소 상황.

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   ⚠️ 정말 삭제하시겠습니까?                         │
│                                                     │
│   이 작업은 되돌릴 수 없습니다.                     │
│   선택한 3개 항목이 영구적으로 삭제됩니다.          │
│                                                     │
│                      [취소]  [삭제]                 │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**버튼 규칙 (Apple HIG):**
- 취소: 좌측, **bold** (위험 액션 시)
- 확인: 우측, danger 스타일

### 5-2. Action Sheet (3+ 선택지)

여러 선택지 제공. "오늘 하기", "내일 하기" 같은 상황.

```
┌─────────────────────────────────────────────────────┐
│  이 항목을 어떻게 처리할까요?                        │
├─────────────────────────────────────────────────────┤
│  [🔴 영구 삭제]                      ← 위험 액션     │
│  [오늘 처리하기]                                    │
│  [내일로 미루기]                                    │
│  [나중에 알림 받기]                                 │
├─────────────────────────────────────────────────────┤
│  [취소]                              ← 분리된 영역   │
└─────────────────────────────────────────────────────┘
```

**배치 규칙:**
- 위험 액션: 상단, 빨간색
- 일반 선택지: 중간
- 취소: 하단, bold, 별도 그룹

### 5-3. Modal with Header (복잡한 작업)

폼 입력이나 상세 확인이 필요한 경우.

```
┌─────────────────────────────────────────────────────┐
│  [취소]        항목 삭제                    [완료]   │
├─────────────────────────────────────────────────────┤
│                                                     │
│   삭제할 항목:                                      │
│   • 대화 1: "안녕하세요..."                         │
│   • 대화 2: "오늘 날씨가..."                        │
│   • 대화 3: "프로젝트 관련..."                      │
│                                                     │
│   ☐ 휴지통으로 이동 (30일 후 삭제)                  │
│   ☐ 즉시 영구 삭제                                  │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**헤더 버튼:**
- 좌측: 취소/뒤로가기 (텍스트 또는 ←)
- 중앙: 제목
- 우측: 완료/확인 (primary 색상)

### 구성 컴포넌트

| 컴포넌트 | Alert | Action Sheet | Modal |
|----------|-------|--------------|-------|
| Header | ✕ | ✕ (제목만) | ✓ |
| Body | 텍스트 | 선택지 버튼 | 폼/컨텐츠 |
| Footer | 2버튼 | 취소 버튼 | ✕ (헤더에) |

### 상호작용

| 동작 | Alert | Action Sheet | Modal |
|------|-------|--------------|-------|
| 오버레이 클릭 | 닫힘 | 닫힘 | 닫힘 |
| ESC 키 | 닫힘 | 닫힘 | 닫힘 |
| 스와이프 다운 | - | 닫힘 | 닫힘 |
| 헤더 X 버튼 | - | - | 닫힘 |

### 선택 가이드

| 상황 | 권장 |
|------|------|
| 단순 확인/취소 | Alert Dialog |
| 2개 이상 선택지 | Action Sheet |
| 추가 입력 필요 | Modal with Header |
| 긴 컨텐츠/스크롤 | Modal with Header |

## 6. 입력 폼 패턴

데이터를 입력받는 패턴.

### 구조

```
┌─────────────────────────────────────────────────────┐
│  라벨                                               │
│  [입력 필드                                    ]    │
│  도움말 텍스트                                      │
│                                                     │
│  라벨                                               │
│  [입력 필드                                    ]    │
│  ⚠️ 에러 메시지                                    │
│                                                     │
│                              [취소]  [저장]         │
└─────────────────────────────────────────────────────┘
```

### 구성 컴포넌트

| 컴포넌트 | 역할 |
|----------|------|
| Label | 필드 이름 |
| Input | 데이터 입력 |
| Hint Text | 도움말 |
| Error Text | 에러 메시지 |
| Button | 액션 |

### 레이아웃

| 요소 | 간격 |
|------|------|
| 필드 간 | 24px |
| 라벨-입력 | 8px |
| 입력-힌트 | 4px |
| 버튼 그룹 | 상단 32px |

### 유효성 검사

| 시점 | 동작 |
|------|------|
| blur | 개별 필드 검증 |
| submit | 전체 검증 |
| 에러 시 | 빨간 테두리 + 에러 메시지 |

## 7. 로딩 상태 패턴

데이터를 불러오는 동안 표시.

### Skeleton

```
┌─────────────────────────────────────────────────────┐
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░           [░░░]   │
│ ░░░░░░░░░░░░░ · ░░░░░░░░                            │
└─────────────────────────────────────────────────────┘
```

### 스타일

| 속성 | 값 |
|------|-----|
| Background | `#E5E7EB` |
| Animation | shimmer (좌→우 그라데이션) |
| Border Radius | 콘텐츠와 동일 |
| Duration | 1.5s, infinite |

### 종류

| 타입 | 용도 |
|------|------|
| Card Skeleton | 카드 로딩 |
| List Skeleton | 목록 로딩 |
| Text Skeleton | 텍스트 로딩 |
| Spinner | 버튼/액션 로딩 |

## 8. 빈 상태 패턴

데이터가 없을 때 표시.

### 구조

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│                    [아이콘/일러스트]                │
│                                                     │
│                  아직 항목이 없습니다               │
│              새로운 항목을 추가해보세요             │
│                                                     │
│                    [+ 추가하기]                     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 구성 컴포넌트

| 컴포넌트 | 역할 |
|----------|------|
| Illustration/Icon | 시각적 표현 |
| Title | 상태 설명 |
| Description | 안내 메시지 |
| Button (옵션) | 다음 액션 유도 |

### 스타일

| 요소 | 스타일 |
|------|--------|
| 아이콘 | 48-64px, text-tertiary |
| 제목 | title-sm, text-secondary |
| 설명 | body-sm, text-tertiary |
| 정렬 | 중앙 정렬 |
| 패딩 | 48px 이상 |

## 반응형 전략 요약

### 브레이크포인트

| 이름 | 값 | 주요 변화 |
|------|-----|-----------|
| sm | 480px | 최소 여백, 심볼 로고 |
| md | 768px | 태블릿 레이아웃, 터치 최적화 |
| lg | 1024px | 데스크톱, 사이드바 가능 |

### 공통 규칙

- 모바일: 단일 컬럼, 전체 너비 버튼
- 태블릿: 2컬럼 그리드, 접이식 영역
- 데스크톱: 다중 컬럼, 모든 요소 표시

### 터치 영역

- 최소 44px × 44px
- 모바일에서 버튼/입력 높이 증가
